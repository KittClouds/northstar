# FC01-FQB-S0 protocol

S0 classifies provenance of values. It never produces values.

The gate reads the sealed finite-box contract, the sealed G5/token contracts,
and the prior failed binding receipt. It records semantic owner, source class,
authority roots, producer/qualification status, derivation operation, and
forbidden inputs for each of the ten parameter classes.

It does not assemble an authorized binding vector, select values, issue a
governance value grant, bind bounds, create an instance, or inspect science.
