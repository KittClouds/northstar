# Finite-box binding-rule qualification protocol

This gate qualifies one deterministic rule descriptor. It does not run the
rule against an actual binding configuration and therefore cannot bind a single
finite-box parameter.

Inputs are limited to sealed finite-box/token/G5 contracts, the static parameter
registry, and the canonicalization contract identifier. Population values,
real histories, realized tokens, pairs, fiber/comparison results, certificates,
coverage, explorer/G8 results, outcomes, and actual binding configuration are
forbidden.

Closure requires exact authorized-input dependency, disjoint forbidden-input
dependency, complete parameter registration, deterministic replay, canonical
descriptor serialization, and fail-closed behavior. A positive result earns no
scientific sufficiency, exhaustiveness, minimality, or box-instance authority.
