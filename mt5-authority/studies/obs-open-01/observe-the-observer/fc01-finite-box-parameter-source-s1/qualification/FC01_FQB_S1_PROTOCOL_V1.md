# FC01-FQB-S1 protocol

S1 classifies the lawful event that could cause a concrete value to exist for
each unresolved extent class. It does not select a value, execute a derivation,
grant governance discretion, assemble the binding vector, or invoke Binding V2.

The five unresolved classes are evaluated independently. Mathematical
resemblance between bounds is not authority for derivation. Absence of a source
is not authority for governance selection.
